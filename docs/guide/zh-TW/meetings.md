# 會議指南

本指南適用於所有召集或參加會議的人：專案例會、CAB 會議、廠商會議、團隊站立會議。**會議**保存您在會議中輸入的筆記，將筆記整理成會議記錄（摘要、決議、待確認事項與待辦事項），並確保待辦事項確實完成：與專案相關的事項會成為該專案看板上的工作項目，其餘事項則在此追蹤，並提醒負責人。

## 您可以在這裡做什麼

- [記錄會議](#記錄會議)並選擇[誰可以閱讀](#誰可以看到會議)
- 在會議中[輸入筆記](#輸入筆記)
- 使用 AI 或依筆記中的標記，[將筆記整理成會議記錄](#將筆記整理成會議記錄)
- [寄送會議記錄](#寄送會議記錄)：通知與會者，專案事項會成為專案工作項目
- [處理您的待辦事項](#處理您的待辦事項)並收到[提醒](#提醒)
- [召開後續會議](#召開後續會議)，列出仍未完成的事項
- 之後在搜尋、助理與專案狀態報告中[找到決議](#之後找到決議)

## 誰可以看到會議

每個人都有**會議參與者**角色：可以記錄會議、閱讀有權檢視的會議，並處理自己的待辦事項。

| 可閱讀的人員 | 誰看得到會議                                                     |
| ------------ | ---------------------------------------------------------------- |
| **私人**     | 召集人、與會者、會議中待辦事項的負責人，以及可閱讀所有會議的人員 |
| **內部**     | 所有使用會議功能的人員                                           |

召集人與與會者可以變更會議的詳細資料、筆記、會議記錄與待辦事項，也可以寄送會議記錄；只有召集人可以刪除會議。沒有參加會議的待辦事項負責人，可以開啟會議閱讀內容，並將自己的事項標示為完成。

**會議閱讀者**角色可以閱讀所有會議（包含私人會議）；**會議管理員**角色可以管理所有會議。這些角色由管理員在**系統管理 → 角色與存取權**中授予。

## 記錄會議

請在會議開始前或結束後立即記錄會議，讓筆記有地方存放。

1. 前往**會議**，選擇**新增會議**。
2. 輸入**標題**、**開始時間**與**時長**。
3. 在**與會者**下，為每位與會者選擇**新增與會者**。您是**召集人**，會自動成為與會者。
4. 如果會議與某個專案有關，請在**專案**中選擇該專案：會議的待辦事項就能成為該專案的工作項目。
5. 選擇**可閱讀的人員**：**私人**或**內部**。在**更多詳細資料**中可以加入**地點**與**來賓**（沒有帳號的人員，輸入姓名即可）。
6. 選擇**建立**。

**接下來會發生什麼：**會議頁面開啟，並顯示**會議記錄尚未寄送**。會議已連結到專案，因此也會出現在專案的連結紀錄中。

> **提示：** 助理可以依對話內容與筆記為您記錄會議，例如請它「用這些筆記記錄昨天的廠商會議」。助理會建立草稿，由您自行整理並寄送。

## 輸入筆記

在會議進行中，用您自己的話在會議頁面的**筆記**欄位輸入筆記，然後選擇**儲存筆記**。每位與會者都可以編輯筆記。

以下標記可以協助整理功能找到重點：

- 以 **待辦：** 或 **TODO** 開頭，或使用核取方塊（`- [ ]`），表示有人需要處理的事。
- 用 **@姓名**（例如 `@林雅婷`）指定負責人，或以姓名加冒號開頭。
- 加上日期：`週五前`、`10/20`、`10月24日` 或 `2026-10-20`。
- 以 **決議：** 開頭，表示已經決定的事項。
- 問題（以 `?` 或 `？` 結尾的行）會列為待確認事項。

英文與日文也適用相同的標記，例如 **Action:** 與 **Decision:**，或 **アクション：** 與 **決定：**。

## 將筆記整理成會議記錄

會議結束後，將筆記整理成會議記錄。

1. 在會議頁面選擇**整理**。尚未儲存的筆記會先儲存。
2. 確認**整理後的會議記錄**：**摘要**、**決議**與**待確認事項**（每行一項）。
3. 確認每個待辦事項：**要做的事**、**負責人**、**期限**，以及**處理方式**：**在此追蹤**，或成為會議所屬專案的工作項目。不需要的事項請取消勾選**新增第 n 項**。
4. 選擇**儲存會議記錄**，或選擇**捨棄**。

**接下來會發生什麼：**會議記錄已儲存，但尚未寄出。會成為工作項目的事項會顯示**寄送會議記錄後成為 NET 的工作項目**。之後可選擇**編輯會議記錄**修改內容，或選擇**新增事項**手動加入待辦事項。

設定 AI 聊天模型時，會議記錄由 AI 以筆記所用的語言整理，頁面會顯示**由 AI 依筆記整理**；沒有設定時，ISBP 會依筆記中的標記整理，並顯示**依筆記整理**。無論哪一種，儲存前都請確認負責人與日期：只有儲存的內容會保留。

> **注意：** 負責人必須是與會者。如果筆記中提到的人沒有參加會議，該事項就不會有負責人，畫面會顯示**筆記中寫的是 …，但他不是與會者**，請自行選擇負責人。

## 寄送會議記錄

寄送會議記錄後，後續追蹤才會開始。

1. 選擇**寄送會議記錄**。
2. 確認視窗會說明有多少位與會者會收到會議記錄、有多少待辦事項開始，以及有多少會成為專案工作項目。選擇**寄送會議記錄**。

**接下來會發生什麼：**

- 與會者會在 ISBP 中與電子郵件收到會議記錄。
- 在此追蹤的事項，其負責人會收到通知。
- 每個專案事項都會以您的身分在專案中建立為工作項目，負責人為指派對象，並帶入期限。頁面會顯示**已建立工作項目 NET-42, NET-43**，並將每個事項連結到其工作項目。專案本身的規則仍然適用：如果您無法在該專案新增工作項目，或負責人不是專案成員，事項會保留在此，並顯示**保留在此：**與原因。
- 會議會連結到它所建立的工作項目。

在示範資料中，**Network refresh — weekly sync** 已寄送會議記錄：其中兩個事項是 **Network refresh 2026** 的工作項目，一個在此追蹤。

## 處理您的待辦事項

前往**會議 → 我的待辦事項**，查看會議中指派給您的事項。

- **我的**列出您負責的事項；**我召集的會議**列出您召集的會議中的事項。
- 可用**未完成**、**已完成**與**全部**篩選。
- 事項完成時選擇**完成**；尚未完成則選擇**重新開啟**。

您在此追蹤的未完成事項，也會列在**我的工作**的**待辦事項**中，期限最近的排在最前面。

已成為專案工作項目的事項，請和其他工作項目一樣在**專案**中處理：工作項目完成時，事項也會顯示為完成；工作項目改派時，事項也會跟著改變。

## 提醒

每天早上，在此追蹤的事項會在到期前一天提醒負責人（**明天到期**）。事項逾期後，每週提醒負責人一次直到完成，第一次也會通知召集人。專案工作項目則由專案模組提醒。

您可以在**個人資料與偏好設定 → 通知**中選擇接收方式：**指派給我的待辦事項**、**明天到期的待辦事項**、**已逾期的待辦事項**與**我參加的會議記錄**。

## 召開後續會議

定期會議可以從上一次會議開始下一次會議。

1. 開啟會議並選擇**後續會議**。

**接下來會發生什麼：**會開啟一個草稿會議，標題、與會者、專案與可閱讀的人員都相同，並顯示返回上次會議的連結（**延續 …**）以及**先前未完成的事項**，方便您逐項檢視仍未完成的事項。

## 之後找到決議

- **搜尋：**會議會出現在每個頁面上方的搜尋結果中（**會議**），可依標題或 MTG-00042 等編號搜尋。
- **助理**可以依討論內容找出會議（例如「我們對核心切換做了什麼決定？」）、列出您的待辦事項，並為您記錄會議，所有操作都依您的權限執行。
- **專案狀態：**專案會議的決議會出現在狀態報告的**會議決議**區段，狀態回報的**幫我擬稿**也會參考這些決議。請參閱[閱讀狀態報告](projects.md#閱讀狀態報告)。

## 與其他功能的關聯

- **專案：**會議事項會成為專案工作項目，會議決議會納入狀態回報與狀態報告：[專案指南](projects.md)。
- **連結的紀錄：**在會議頁面的**連結的紀錄**中，將會議連結到相關的變更、工單或組態項目。
- **我的工作：**您未完成的待辦事項會和其他待處理的工作一起列出：[員工指南](employees.md)。
- **助理：**[助理與 AI](assistant-and-ai.md)。
