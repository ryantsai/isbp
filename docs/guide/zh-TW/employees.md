## 在申請頁面找到您需要的項目

**申請**是 IT 的單一入口。每當您需要 IT 提供某項服務，或想知道申請的進度時，就到這裡。

1. 選擇側邊欄中的**申請**。
2. 在**您需要什麼？** 下選擇一張卡片：

| 卡片               | 適用時機                                                                                                  |
| ------------------ | --------------------------------------------------------------------------------------------------------- |
| **回報問題**       | 某項功能無法正常運作，您希望服務台修正（[詳細說明](#回報問題)）                                           |
| **我的設備**       | 您想查看 IT 配發給您的筆電、手機與軟體，或回報其中一項的問題（[詳細說明](#查看您的設備並回報設備問題)）   |
| **瀏覽知識庫**     | 您想依照逐步說明的文章自行解決                                                                            |
| **申請資料庫存取** | 您需要在一段期間內取得 SQL Server、Oracle 或 PostgreSQL 資料庫上的角色（[詳細說明](#申請資料庫存取)）     |
| **申請權限**       | 您需要平台或業務應用程式中的角色（[詳細說明](#申請應用程式或角色的權限)）                                 |
| 申請表單           | 您需要設備、軟體或 IT 提供的其他項目，例如示範資料中的**筆電申請**（[詳細說明](#使用表單申請設備或軟體)） |

標示**需要簽核**的卡片會先送交簽核者，IT 才會處理。申請表單依類別分組（**硬體**、**軟體**、**資訊安全**、**權限**、**其他**）。卡片上方的**詢問 IT** 可以立即回答您的問題（[詳細說明](#建立工單前先詢問-it)）。

![申請頁面，含詢問 IT 卡片、申請卡片與我的申請](../../../apps/web/public/help/zh-TW/employees-portal.jpg)

> **提示：** 您只會看到開放給您的表單。如果同事提到某份表單而您找不到，可能是該表單只開放給部分群組：請參閱[入口網站中沒有某份表單](faq.md#入口網站中沒有某份表單)。

## 使用表單申請設備或軟體

當您需要新筆電、螢幕、軟體授權或 IT 提供的其他項目時，請使用申請表單。表單會詢問 IT 需要知道的資訊，所需的簽核也已設定在表單上。

1. 前往**申請**，在**您需要什麼？** 下選擇表單。
2. 填寫欄位。有些問題只在適用時才會出現：例如在**申請筆電或設備**中，必須先將**品項**選為**筆記型電腦**，才會出現**筆電型號**。
3. 選擇**送出**。如果有必填欄位未填，表單會在該欄位旁顯示**此欄位為必填**。

**後續流程：** 申請會取得 `REQ-01042` 這類編號，並在自己的頁面上開啟，顯示其**簽核路徑**。如果表單需要簽核（頁面會顯示**此申請需經過簽核，每個步驟都會通知您。**），申請會送交第一位簽核者。所有人都核准後，IT 就會處理：許多表單會成為服務台工單，申請頁面會顯示工單的進度（**處理中**，接著是**已完成**）及工單的連結（**開啟 SR-…**）。申請核准或遭駁回時，您都會收到通知。

> **提示：** 在示範資料中，**筆電申請**表單會詢問**預估金額（新台幣）**。部門主管會簽核每一份筆電申請；金額超過新台幣 60,000 元時，還需經 IT 資產管理簽核。核准後的申請會成為**硬體 › 筆電**類別中的服務台工單。

## 申請應用程式或角色的權限

當您需要 IS Big Platform 中的角色，例如**公告編輯者**（Announcement editor），或需要在 ISBP 中登錄之業務應用程式的角色（在示範資料中為 **Finance ERP**、**HR Portal** 與 **Expense Claims**）時，請使用**申請權限**。您需要說明使用期間與原因，並在送出前看到由誰簽核。

1. 前往**申請**，選擇**申請權限**。
2. 選擇您需要的權限。可以使用**搜尋角色與應用程式…** 或應用程式按鈕縮小清單範圍。每個角色都會顯示其風險（**低風險**、**中風險**、**高風險**）、擁有者，以及可授予的最長期間（例如**最長 90 天**）。您已擁有的角色會標示**您已擁有**；已申請過的角色會顯示**已申請（REQ-…）**。
3. 選擇**繼續**。
4. 在**誰需要此權限？** 下選擇**我自己**或**其他人**。主管可以為直屬部屬申請；存取權管理員可以為任何人申請。尚未到職的新進人員會標示為**預先建立**：您為他們申請的存取權，會在他們到職第一天就緒。
5. 在**使用期間**下選擇 **7 天**、**30 天**、**90 天**、**自訂**（輸入**天數**），或在角色允許時選擇**無到期日**。
6. 在**申請原因**下輸入至少 10 個字元。簽核者會閱讀這段說明，所以請具體說明，例如：「主管休假期間，由我核准服務台團隊的費用申請。」
7. 選擇**確認**。檢查**您的申請**與**簽核者**：也就是依目前的簽核流程與組織架構推算出的各步驟簽核人員。
8. 選擇**送出申請**。

![在申請權限精靈中選擇要申請的權限](../../../apps/web/public/help/zh-TW/employees-access-request.jpg)

**後續流程：** 申請開啟後的狀態為**待簽核**。根據預設，申請會先送交您的**主管簽核**，高風險角色會再經過**資安審查**，然後是**權限擁有者簽核**。有些角色使用自己的簽核流程；確認步驟一律會顯示實際的路徑。最後一位簽核者同意後，系統會自動授予角色，申請頁面會顯示**已授予權限，將於 … 到期**（或**已授予權限，沒有到期日**）。有期限的存取權會在到期時自動移除；到期前幾天您會收到提醒（**即將到期的權限**）。

> **重要：** 如果確認步驟顯示**此步驟沒有人能核准，申請將遭駁回**，表示目前沒有人可以替您核准這個步驟。請不要送出：先洽服務台或角色擁有者。

## 建立工單前先詢問 IT

**詢問 IT** 是一個虛擬客服，隨時以您的語言依據知識庫回答 IT 問題。大多數問題（VPN、密碼、MFA、印表機）都能在幾秒內得到解答，不需要工單。若它無法解決，會為您準備一張工單，在您確認之前不會送出任何內容。

1. 選擇側邊欄中的**詢問 IT**，或**申請**頁面上的**提出問題**。
2. 用自己的話以任何語言描述問題，或從**建議的問題**中選擇一個（例如 **VPN 無法連線**）。按 Enter 或選擇**傳送**。
3. 閱讀回答。回答所參考的文章會列在**參考來源**下；開啟文章即可查看完整步驟。
4. 在**問題解決了嗎？** 下選擇**已解決**或**仍需要協助**。
5. 如果仍需要協助，詢問 IT 會顯示**還是沒解決嗎？我已為服務台準備好一張工單。** 選擇**檢視工單**，檢查**標題**、**說明**、**緊急程度**與**類型**（**有東西故障了**或**我需要某項服務**），然後選擇**建立工單**。若想繼續對話，請選擇**暫時不要**。

![詢問 IT 虛擬客服與建議的問題](../../../apps/web/public/help/zh-TW/employees-ask-it.jpg)

**後續流程：** 詢問 IT 會顯示**已建立工單 INC-…，服務台會在工單中與您聯繫。** 並提供**檢視工單**。這張工單會和您回報的其他工單一樣，出現在**我的申請**下。您先前的對話會列在**對話**下；選擇**新對話**即可開始新的對話。

> **提示：** 對話頂端的標記說明回答是如何產生的。**內建 · 未使用 LLM** 表示尚未設定 AI 語言模型：回答來自知識庫搜尋與範本。**語言模型**表示由 AI 模型依據知識庫撰寫回答，並會先遮罩個人資料。無論哪一種，回答都可能有誤：請查看連結的文章。請參閱[助理與 AI](assistant-and-ai.md)。

## 回報問題

當某項功能故障，而您希望服務台人員修正時，請回報問題：例如 VPN 一直斷線、Outlook 無法同步、印表機卡紙。

1. 前往**申請**，選擇**回報問題**。
2. 在**發生了什麼問題？** 下用幾個字描述，例如「在家無法連上 VPN」。
3. 在**補充說明**下，說明發生了什麼事、從何時開始、您已嘗試過什麼，以及任何錯誤訊息。
4. 在**對您的影響有多大？** 下選擇**我無法工作**、**拖慢了我的工作**或**影響不大**。
5. 您也可以在**哪個服務？** 下選擇相關的系統（選填）。
6. 在您輸入時，**這些文章或許有幫助**會建議知識文章。如果其中一篇解決了問題，就不需要送出回報。
7. 選擇**送交服務台**。

**後續流程：** 畫面會顯示**已送出 INC-…，我們會盡快處理。** 並開啟工單。您會收到服務台已受理的通知，工單也會出現在**我的申請**下。工單頁面會顯示其進度（**已回報**、**處理中**、**已解決**、**已結案**）、由誰處理（**處理單位**），以及與服務台的**對話**。若要補充細節或回答問題，請在回覆框中輸入並選擇**送出回覆**；螢幕截圖請加入**附件**。處理人員回覆或工單解決時，您會收到通知。服務台的回應與解決時間會依 SLA 追蹤；請參閱[服務台](service-desk.md)。

## 追蹤您的申請

**申請**頁面底部的**我的申請**會列出您提出的所有事項：權限申請、表單申請、您回報的工單，以及資料庫存取申請。

1. 前往**申請**，捲動到**我的申請**。
2. 選擇**進行中**、**已結束**或**全部**。
3. 每一列都會顯示編號、上次變更的時間及狀態。申請等待簽核時，該列會顯示**等候 …**，以及步驟名稱與簽核者的頭像。
4. 選擇一列即可開啟申請。

| 您看到的狀態                                                       | 意義                                                |
| ------------------------------------------------------------------ | --------------------------------------------------- |
| **待簽核**                                                         | 簽核者尚未決定；申請頁面會顯示是誰（**等候**）      |
| **已核准**／**已駁回**                                             | 已決定。駁回時，**駁回原因：** 下會顯示簽核者的原因 |
| **已撤回**                                                         | 您（或代您申請的人）已將其撤回                      |
| **無法授予**                                                       | 已核准，但角色已不存在，或該人員已非啟用狀態        |
| **新建**、**處理中**、**暫停**、**已解決**、**已完成**、**已結案** | 工單，或透過工單處理中的表單申請                    |
| **設定中**、**已授予存取**、**已結束**、**已移除**                 | 資料庫存取（[詳細說明](#申請資料庫存取)）           |

申請頁面會顯示**簽核路徑**（每個步驟、由誰在何時決定）與**歷程**。權限申請還會顯示角色、**對象**、**期間**與**申請原因**；表單則會顯示您的**填寫內容**。

> **提示：** **儀表板**也會顯示**您進行中的申請**，簽核者還會看到**待您簽核**。

### 確認問題已解決並為服務評分

服務台解決您的工單後，會請您確認。

1. 從通知或**我的申請**開啟工單。工單頁面會顯示**問題解決了嗎？**
2. 如果已恢復正常，請選擇**是，可以結案**，並可在**對這次的服務滿意嗎？（選填）** 下為服務評分及留下意見，然後選擇**結案**。
3. 如果仍有問題，請選擇**不，還是有問題**，在**還有哪裡不對？** 中說明，然後選擇**重新開啟工單**。

**後續流程：** 結案的工單在**我的申請**中會變為**已結案**。重新開啟的工單會回到服務台，處理人員也會收到附有您原因的通知。

### 撤回申請

權限申請或表單申請只要仍在等待簽核，您就可以撤回不再需要的申請。

1. 從**我的申請**開啟申請。
2. 選擇**撤回**，然後在**要撤回此申請嗎？** 中再次選擇**撤回**（若改變主意，請選擇**保留**）。

**後續流程：** 申請會顯示**已撤回**，簽核者也不會再看到它。之後您可以重新送出申請。

## 查看您的設備並回報設備問題

**我的設備**會列出 IT 配發給您的筆電、手機與其他硬體，以及個人配發給您的軟體授權。您可以用它查看資產編號或保固，或回報特定設備的問題。

1. 前往**申請**，選擇**我的設備**。
2. 每台設備都會顯示其**資產編號**、**序號**、**使用起始**與**保固**。
3. 若要回報某台設備的問題，請在該設備上選擇**回報問題**。

**後續流程：** **回報問題**頁面會開啟，並已連結該設備，讓服務台知道是哪一台。如果清單顯示**目前沒有配發給您的設備**，但您有公司設備，請選擇**通知服務台**，讓他們登錄設備。在示範資料中，服務台組長（`helpdesk`）有一台筆電與一支手機。

## 申請資料庫存取

開發人員、分析師與支援人員有時需要在一段有限的時間內取得資料庫上的角色。ISBP 會處理整個流程：簽核、建立帳號、讓您查看一次密碼，以及在到期時移除存取權。

1. 前往**申請**，選擇**申請資料庫存取**。
2. 依序完成**選擇角色**、**期限與原因**與**確認並送出**。
3. 存取權就緒時（**您的存取已就緒**通知），開啟**資料庫存取 → 我的資料庫存取**並選擇**顯示密碼**。密碼只會顯示一次，且僅在帳號建立後 7 天內可以顯示：請將密碼存入密碼管理工具。

簽核會先送交您的**主管簽核**，接著是**角色擁有者簽核**，高風險角色還需經過**資訊安全簽核**。詳細說明：[資料與自動化](data-and-automation.md)。

## 核准或駁回申請

如果您是主管、角色或應用程式擁有者、CAB 成員，或屬於負責簽核的群組，申請就會送交您決定。請盡快決定：簽核步驟有期限，期限前會有提醒，而有些簽核流程會在逾期時將申請呈報給其他人。

1. 選擇側邊欄中的**簽核**。旁邊的數字表示有多少項決定在等待您。**待我簽核**會列出這些項目，最緊急的排在最前面；每一項都會顯示簽核流程、步驟、申請人，以及期限標記，例如 **5 小時內到期**或**已逾期 2 天**。
2. 若要先查看詳細資料，請選擇該申請。面板會顯示**申請內容**、**簽核路徑**、**歷程**，以及**開啟申請**連結。
3. 選擇**核准**或**駁回**。
4. 在對話方塊中加入意見：核准時為選填（**意見（選填）**），駁回時為必填（**駁回原因**）。申請人會看到這些意見。
5. 在對話方塊中選擇**核准**或**駁回**。

![簽核收件匣與等待決定的申請](../../../apps/web/public/help/zh-TW/employees-approvals.jpg)

**後續流程：** 申請會進入下一個步驟，或就此完成。申請人會收到通知並看到您的意見。**我已簽核**會列出您已決定的項目。如果已有其他人先做出決定（在「以第一個回應為準」的步驟中），您會看到**此簽核已經處理過了。**

> **提示：** 您可以依編號搜尋收件匣（**搜尋申請…**）。新的簽核會在應用程式內通知您；若已設定電子郵件，也會以電子郵件通知（**待我簽核**）。

同一個收件匣處理 ISBP 中所有類型的簽核：權限申請、表單申請、變更（CAB）、資產報廢、專案提案、資料庫存取、知識文章，以及透過助理準備的變更集。步驟呈報給您時會顯示**已轉呈給您**標記；同事轉交給您時則顯示**來自 …**。

## 將簽核轉交給其他人

當同事更適合做決定時（例如他們更熟悉該系統），請轉交簽核。

1. 在**簽核**中選擇該申請，開啟其面板。
2. 選擇**轉交**。
3. 選擇**同事**，視需要填寫**給對方的備註（選填）**，然後選擇**轉交**。

**後續流程：** 簽核會移到對方的收件匣，對方也會收到通知。申請人無法決定自己的申請。如果沒有**轉交**，表示該簽核流程步驟不允許轉交。

## 休假前設定不在辦公室

排定不在辦公室，讓簽核不會在您不在時停滯。

1. 開啟使用者選單（右上角的頭像），選擇**個人資料與偏好設定**。
2. 前往**不在辦公室**，選擇**排定**。
3. 在**將我的簽核交給**下選擇一位同事。設定**開始**與**結束**（或使用快速的**期間**），並可填寫**原因**，例如「年假」。
4. 選擇**排定不在辦公室**。

**後續流程：** 在這段期間內，新的簽核工作會改為交給您的代理人；已在等待您處理的工作仍由您負責。此期間會先顯示為**已排定**，接著顯示為**進行中**。選擇**立即結束**可以提早回來，選擇**移除**則可取消已規劃的期間。在示範資料中，HR 業務夥伴（`hr.partner`）已排定年假，簽核會交給服務台組長。

## 選擇要接收哪些通知

ISBP 會在應用程式內（頁首的鈴鐺）與透過電子郵件，通知您簽核、您的申請、工單等相關事項。

1. 開啟使用者選單，選擇**個人資料與偏好設定**，再選擇**通知**。
2. 針對每種**通知**類型，開啟或關閉**應用程式內**與**電子郵件**。變更會自動儲存。
3. **還原為預設值**可恢復原始設定。

**後續流程：** 新的通知會依照您的選擇傳送。標示**基於安全性必須接收**的類型無法關閉。如果頁面顯示本平台尚未設定電子郵件通知，在管理員開啟電子郵件功能之前，您只會在應用程式內收到通知。

若要閱讀通知，請選擇鈴鐺：選擇某則通知即可開啟相關內容，或選擇**全部標示為已讀**。**檢視所有通知**會開啟完整清單，並提供**全部**與**未讀**分頁。

## 設定語言、時區與工作階段

您的偏好設定會跟著您到每一部登入的裝置。

1. 開啟使用者選單，選擇**個人資料與偏好設定**。
2. 在**偏好設定**下，選擇**語言**（也用於通知與電子郵件）、佈景主題，以及您的**時區**（日期與時間會以此時區顯示）。**使用此裝置的時區**會依您的電腦設定時區。
3. 在**個人資料**下變更您的**顯示名稱**。電子郵件、使用者名稱與部門由貴組織管理。
4. 若您以本機帳號登入，可以在**密碼**下變更密碼。若您透過貴組織登入，請在該處變更。
5. 在**工作階段**下，檢查已登入您帳號的裝置。在不認得的裝置旁選擇**登出**，或選擇**登出其他工作階段**。

### 查看您擁有哪些角色

**個人資料與偏好設定**底部的**我的存取權**會列出您的角色及其取得方式（**直接指派給您**、**透過群組**加上群組名稱，或**所有人**），有期限的角色也會顯示到期日。如果缺少您需要的權限，請[申請權限](#申請應用程式或角色的權限)。
