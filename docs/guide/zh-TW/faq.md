## 登入

### 我的帳號被鎖定了

**嘗試失敗次數過多，請過幾分鐘後再試。** 表示 ISBP 在多次輸入錯誤密碼後，暫時鎖定了帳號。請稍候再試。如果您忘記本機帳號的密碼，請服務台為您設定新密碼；如果您以公司帳號登入（**使用 … 登入**），請在公司帳號處重設密碼。請參閱[登入](README.md#登入)。

### 登入時 ISBP 要求我設定新密碼

管理員給了您一組密碼（新帳號，或為您設定的密碼），並要求您更換。請在**目前的密碼**中輸入您拿到的密碼，再輸入兩次至少 10 個字元的**新密碼**，然後選擇**變更密碼**。在您完成之前，每次開啟 ISBP 都會回到**請設定新密碼**。請參閱[登入](README.md#登入)。

### 畫面顯示我的帳號尚未建立

**您的帳號尚未在此平台上建立。** 表示您的公司帳號可以使用，但 ISBP 中沒有您的人員資料。請服務台或身分識別管理員將您加入。**此帳號未啟用，請聯絡您的管理員。** 表示您的帳號處於預先建立、停權或離職停用狀態。

### 我被登出了

您的工作階段結束，或您的工作階段被登出時（例如變更密碼後，或在另一部裝置上使用了**登出其他工作階段**），會出現**您的工作階段已逾時，請重新登入。** 請重新登入。若要在自己的裝置上保持登入，請勾選**在此裝置上保持登入**。

## 存取權與權限

### 我看不到某個頁面或按鈕

ISBP 只會顯示您的角色允許的內容。您無法使用的頁面不會出現在側邊欄中，直接開啟時會顯示**您沒有存取此頁面的權限。**

1. 開啟**個人資料與偏好設定 → 我的存取權**查看您的角色。
2. 如果需要更多權限：若該角色可申請，請[申請權限](employees.md#申請應用程式或角色的權限)；否則請洽您的主管或管理員。

以下是一些範例：**服務台**頁面需要**服務台專員**（Service desk agent）角色；**整合**需要**整合管理員**（Integrations administrator）或**整合檢視者**（Integrations viewer）角色；**助理**按鈕需要**助理使用者**（Assistant user）角色。如果看到**此頁面不存在，或該模組已停用。** 表示管理員已在**系統管理 → 模組**中關閉了該區域。

### 我可以為尚未到職的新同事申請權限嗎？

可以。HR 將對方新增為**預先建立**後，請在**申請權限**中選擇**其他人**並選擇對方：對方會標示為**預先建立**。申請核准後，系統就會授予存取權，並從 HR 在對方到職第一天選擇**到職啟用**的那一刻起生效。請參閱[新進人員週一報到](how-it-fits-our-work.md#情境新進人員週一報到)。

預先建立的人員只會顯示給其主管，以及負責管理其部門存取權的人員；如果找不到對方，請確認 HR 已將您設為其**主管**。**此人員已停權，請先重新啟用。** 與**此人員已離職停用。** 表示該人員的帳號已停權或已關閉：無法再為其申請新的存取權。

## 申請與簽核

### 我的申請卡住了，正在等誰？

從**申請 → 我的申請**開啟申請。**簽核路徑**會顯示每個步驟；目前步驟會顯示**等候**並列出簽核者的名字。**我的申請**中的該列也會顯示**等候 …** 及簽核者的頭像。

- 簽核步驟有期限。簽核者會收到提醒，而視簽核流程而定，申請可能會在逾期時呈報（例如呈報給主管的主管）。
- 如果簽核者不在，新的簽核會交給其不在辦公室的代理人。您可以直接聯絡簽核者，或洽服務台。
- 管理員可以在**系統管理 → 工作流程 → 進行中與歷史紀錄**中查看所有進行中的簽核，以及每項簽核的**目前步驟**。

### 簽核路徑顯示「已略過：找不到簽核者」

簽核流程找不到該步驟的簽核者（例如您的個人資料中沒有主管），而該步驟設定為略過。如果確認步驟或表單上的**誰會核准此申請？** 顯示**此步驟沒有人能核准，申請將遭駁回**，請不要送出申請：先請服務台修正您的主管、角色的擁有者，或（在表單上）您所選系統的支援群組。

### 畫面顯示「尚未設定此項目的簽核流程」

此申請需要的簽核流程尚未發佈。請管理員在**系統管理 → 工作流程**中發佈一個。請參閱[管理員](administrators.md)。

### 畫面顯示「此存取權限已有進行中的申請。」

您（或代您申請的人）已申請過該角色，且仍在等待中。請從**我的申請**開啟該申請；如果想送出不同的申請，請先將其撤回。

### 權限已核准，但我還沒有拿到

授予會在最後一次核准後片刻完成。重新載入申請：應該會顯示**已授予權限**。如果顯示**無法授予**，表示角色已被刪除，或該人員已非啟用狀態；請洽服務台。

### 我要決定的簽核顯示「此簽核已經處理過了。」

該步驟中的其他人先做了決定（許多步驟以第一個回應為準），或申請已被撤回。只有在您做過決定時，它才會出現在**簽核 → 我已簽核**中。

### 我要休假了，我的簽核要如何繼續進行？

在**個人資料與偏好設定 → 不在辦公室**中排定不在辦公室：新的簽核會交給您選擇的同事。請參閱[設定不在辦公室](employees.md#休假前設定不在辦公室)。

### 申請入口網站中沒有某份表單

表單只有在符合以下所有條件時，才會出現在**申請 → 您需要什麼？** 下。請工作流程管理員在**系統管理 → 表單**中檢查：

- 表單已發佈（其狀態顯示**已發佈 v…**，而不是**草稿**）。
- **接受申請**已開啟（否則會顯示**已暫停**）。
- 其**適用對象**為**所有人**，或包含您的**特定群組**。
- 其簽核流程已發佈。

請參閱[管理員](administrators.md)。

### 表單的紀錄選取器找不到我需要的組態項目（或應用程式、資產）

紀錄選取器只會列出您有權限檢視、且表單接受的紀錄：例如，表單可能只提供正式環境的系統。請在**依編號或標題搜尋…** 下輸入編號或名稱的一部分。如果紀錄仍然沒有出現，您可能沒有檢視該類紀錄的角色（組態項目為 **CMDB 檢視者**）：請洽服務台或維護該表單的人員。請參閱[讓人員選取紀錄](processes.md#讓人員選取紀錄)。

### 我的申請已核准，但「後續動作」顯示失敗

表單在核准後嘗試執行某項作業（例如建立變更），但沒有成功。維護表單的人員已收到附有錯誤的通知，修正原因後可以用**重試**重新執行。（**重試中（第 … 次）** 表示系統仍在自動重試。）您不需要重新送出申請。請參閱[追蹤動作的執行結果](processes.md#追蹤動作的執行結果)。

### 我要在哪裡找到表單的連結？

每份已發佈的表單都有自己的網址，也就是我們 ISBP 位址上的 `/requests/forms/<key>`。管理員可以在表單編輯器中以**更多動作 → 在申請入口網站開啟**開啟它，再從瀏覽器複製網址。不在表單**適用對象**中的人員會看到「此表單目前無法使用」。請參閱[發佈表單並分享連結](processes.md#發佈表單並分享連結)。

## 通知與語言

### 我沒有收到通知

1. 檢查**個人資料與偏好設定 → 通知**：該類型必須開啟**應用程式內**或**電子郵件**。
2. 如果頁面顯示本平台尚未設定電子郵件通知，您只會在應用程式內收到通知。管理員可以在**系統管理 → 通知 → 電子郵件**中開啟電子郵件功能。
3. 傳送到 Microsoft Teams 或 Slack 的通知，會送到管理員在**系統管理 → 通知 → 通道**中設定的團隊通道，而不是傳給您個人。
4. 管理員可以在**系統管理 → 通知 → 傳送紀錄**中查看已傳送與傳送失敗的通知。

請參閱[選擇要接收哪些通知](employees.md#選擇要接收哪些通知)。

### 通知與電子郵件使用哪種語言？

您的語言。每則通知在傳送時都會以收件者的語言撰寫，因此變更**語言**只會影響新的通知，不會影響舊的通知。張貼到 Teams 或 Slack 通道的訊息則使用該通道的**訊息語言**。

### 日期與時間看起來不對

在**個人資料與偏好設定 → 偏好設定**中設定您的**時區**，或選擇**使用此裝置的時區**。

## 工單與服務台

### 我的工單已解決，但問題仍然存在

開啟工單，選擇**不，還是有問題**，在**還有哪裡不對？** 中說明，然後選擇**重新開啟工單**。服務台會收到通知。請參閱[確認問題已解決](employees.md#確認問題已解決並為服務評分)。

### 詢問 IT 為我建立的工單在哪裡？

與您回報的其他工單一樣，在**申請 → 我的申請**下。詢問 IT 也會在對話中提供工單的連結（**檢視工單**）。

## 詢問 IT、助理與變更集

### 詢問 IT 顯示「內建 · 未使用 LLM」

尚未設定 AI 語言模型。詢問 IT 仍可運作：它會依據知識庫搜尋、相似工單與範本回答，也仍然可以準備工單。**語言模型**表示由 AI 模型撰寫回答。管理員可以在**系統管理 → AI** 中選擇模型。請參閱[助理與 AI](assistant-and-ai.md)。

### 助理只提供引導式範本

未設定 AI 對話模型時，助理會提供**引導式範本**（例如**簽核鏈**、**申請表單**、**自訂欄位**、**SLA 目標**與 **HTTP 健康檢查**），而不是讓您自由輸入文字。如果顯示**您可以變更的項目沒有引導式範本**，表示您沒有它可以變更之任何設定的存取權。

### 畫面顯示「本月的 AI 預算已用完。」

管理員設定的每月 AI 預算（**系統管理 → AI → 隱私與預算**）已用完，因此在下個月或管理員提高預算之前，不會呼叫 AI 模型。您仍然可以建立工單。

### 變更集顯示「變更集準備完成後，有人修改了此設定。」

這是 `CHANGE_SET_STALE` 錯誤。在變更集準備完成後，有人編輯了相同的簽核流程、表單或設定，因此套用它會覆寫對方的工作。

1. 在**系統管理 → 變更集**中開啟該變更集。
2. 選擇**重新整理**：變更集會改用目前的版本。
3. 檢閱差異與**試行**結果，然後再次套用或要求審核。

### 畫面顯示「您無法自行套用此變更集」

套用它需要您沒有的權限。請選擇**要求審核**：具有這些權限的簽核者會在**簽核**中審核，核准即會套用變更集。

### 變更集無法回復

回復會一次復原所有變更，因此當其中某個物件之後被變更過，或變更集刪除了某些內容時（刪除無法自動復原），系統會拒絕回復。請改用新的變更集進行修正。請參閱[助理與 AI](assistant-and-ai.md)。

## 資料、作業與資料庫存取

### 排程作業失敗了

1. 開啟**排程作業 → 執行紀錄**，篩選**失敗**並開啟該次執行。**失敗原因**會顯示錯誤。
2. 修正原因（例如無法連線的資料庫連線），然後選擇**再次執行**。
3. 如果作業連續失敗多次，就會被停用（**… 已停用**）：開啟作業並選擇**啟用**。

作業的警示開啟時，作業擁有者會收到**我的作業執行失敗**通知。請參閱[資料與自動化](data-and-automation.md)。

### 「無法在此執行指令碼：尚未設定沙箱，或不允許使用此映像檔。」

指令碼作業會在隔離的容器中執行，這些容器必須由管理員設定。請洽平台管理員。請參閱[資料與自動化](data-and-automation.md)。

### 我再也看不到資料庫密碼了

**此密碼已顯示過或已過期。** 密碼只會顯示一次，且僅在帳號建立後 7 天內可以顯示。請 DBA 重設密碼。

### 正式環境部署遭拒：「部署至正式環境前需要已核准的變更。」

正式環境的部署需要一項經 CAB 核准的變更（**已排程**或**實施中**），該變更必須在部署上指定或連結到發行版本，有時還必須在其預計時段內。請連結已核准的變更；若您是變更經理，也可以使用**提出變更**提出一項變更。請參閱[變更與發行](changes-and-releases.md)。

## 整合

### 發生同步衝突

自上次同步以來，同一欄位在 ISBP 與 ServiceDesk Plus 或 Azure DevOps Server 中都被變更了，而設定檔要求由人員決定。

1. 前往**系統管理 → 整合 → 同步衝突**。
2. 在衝突上選擇**解決**。
3. 針對每個欄位，選擇**保留 ISBP 的值**或**保留 … 的值**，或選擇**保持雙方現狀**，然後選擇**套用**。

您需要解決同步衝突的權限（**整合管理員**角色）。請參閱[整合](integrations.md)。

### 「連接的系統拒絕了此連線的認證資訊。」

為連線儲存的 API 金鑰或個人存取權杖錯誤或已過期。請整合管理員在連線設定中更新。

### 「此連線使用未加密的 HTTP。」

連線預設使用 HTTPS。請使用該系統的 HTTPS 位址；只有在無法使用 HTTPS 時，管理員才可以為該連線開啟**允許不安全的 HTTP**（此開關的變更會被稽核）。
