# 詞彙表

IS Big Platform 與本指南中使用的詞彙，以英文、繁體中文與日本語列出，用詞與畫面上顯示的文字一致。您可以用它找出某個標籤在其他語言中的說法，或確認某個詞彙在我們的工作中代表什麼意思。

## 您可以在這裡做什麼

- 在[詞彙一覽](#詞彙一覽)中查詢詞彙，詞彙依英文的字母順序排列
- 透過[與其他工作的關聯](#與其他工作的關聯)中的連結，前往使用這些詞彙的指南

| Sessions                  | 工作階段              | セッション                   | 已登入您帳號的裝置與瀏覽器                                                                                                                                            |
| Shared account            | 共用帳號              | 共有アカウント               | 由多人使用的帳號（服務帳號或設備管理者帳號），有主要保管者與使用人員清單；有人離開清單時須變更密碼                                                                    |
| Sign off                  | 核定                  | 確定                         | 資訊安全主管對盤點或帳號清查的最終確認。不是簽核：不會出現在**簽核**中                                                                                                |
| SLA                       | SLA                   | SLA                          | 服務等級協議：回應與解決目標，依營業時間計算                                                                                                                          |
| Stocktake                 | 資產盤點              | 棚卸                         | 確認資訊資產清冊仍與實際相符：各負責人確認或更正自己的資產，再由資訊安全主管核定（`STK-…`）                                                                           |
| Sync rule                 | 同步規則              | 同期ルール                   | 整合與 ServiceDesk Plus 或 Azure DevOps Server 同步哪些內容、方向為何，以及使用哪些欄位對應                                                                           |
| Task                      | 工作項目              | タスク                       | 專案中的一項工作，顯示在看板與時程上                                                                                                                                  |
| Ticket                    | 工單                  | チケット                     | 服務台的紀錄：事件、服務請求、問題或變更                                                                                                                              |
| Workload                  | 工作負載              | 作業負荷                     | 每人每週的計畫工時，並與其可用產能比較                                                                                                                                |

> **提示：** 在繁體中文中，「簽核」指簽核的流程（**簽核**、簽核流程、簽核路徑、待簽核、簽核者），「核准」則指決定本身（核准、已核准）。「紀錄」是名詞，指一筆紀錄或日誌項目（執行紀錄、連結的紀錄），「記錄」則是動詞（「記錄在稽核日誌中」）；執行過程的日誌檔案稱為「記錄檔」。「回復」是指回復變更集、部署或管線的載入，「復原」則是指還原操作。「發佈」指發佈（已發佈），「代碼」是群組、角色、表單或應用程式的代碼（API 金鑰則稱為「金鑰」），「通道」是通知通道。在日本語中，permission 譯為「アクセス許可」，「権限」只出現在「最小権限」（least privilege）等固定用語中；作業、管線或同步規則的執行清單稱為「実行履歴」，彼此連結的紀錄稱為「関連レコード」。角色名稱會依讀者的語言顯示；組織自行建立的角色則保留其原本的名稱。指南引用標籤時，會使用該畫面上的確切文字。
