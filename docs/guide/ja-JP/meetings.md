# 会議ガイド

このガイドは、会議を主催または参加するすべての人を対象としています。プロジェクトの定例会議、CAB 会議、ベンダーとの打ち合わせ、チームの朝会などです。**会議**は、会議中に入力したメモを保存し、議事録 (概要、決定事項、未決事項、アクション アイテム) に整理して、アクション アイテムが確実に完了するようにします。プロジェクトに関するアイテムはそのプロジェクトのボードのタスクになり、それ以外のアイテムはここで追跡され、担当者にリマインドされます。

## ここでできること

- [会議を記録](#会議を記録する)し、[閲覧できるユーザー](#会議を閲覧できるユーザー)を選ぶ
- 会議中に[メモを入力](#メモを入力する)する
- AI またはメモ内の目印をもとに[メモを議事録に整理](#メモを議事録に整理する)する
- [議事録を送信](#議事録を送信する)する: 参加者に通知され、プロジェクトのアイテムはプロジェクトのタスクになります
- [自分のアクション アイテムに取り組み](#自分のアクション-アイテムに取り組む)、[リマインダー](#リマインダー)を受け取る
- 未完了の項目を一覧にした[フォローアップ会議を開く](#フォローアップ会議を開く)
- 検索、アシスタント、プロジェクトのステータス レポートで[あとから決定事項を探す](#あとから決定事項を探す)

## 会議を閲覧できるユーザー

すべてのユーザーが**会議の参加者**ロールを持っています。会議を記録し、閲覧できる会議を読み、自分のアクション アイテムに取り組めます。

| 閲覧できるユーザー | 会議を表示できるユーザー                                                        |
| ------------------ | ------------------------------------------------------------------------------- |
| **非公開**         | 主催者、参加者、会議のアクション アイテムの担当者、すべての会議を読めるユーザー |
| **社内**           | 会議を使用するすべてのユーザー                                                  |

主催者と参加者は、会議の詳細、メモ、議事録、アクション アイテムを変更でき、議事録を送信できます。会議を削除できるのは主催者だけです。会議に参加していないアクション アイテムの担当者は、会議を開いて内容を読み、自分のアイテムを完了にできます。

**会議の閲覧者**ロールは非公開を含むすべての会議を読めます。**会議の管理者**ロールはすべての会議を管理できます。これらのロールは、管理者が**管理 → ロールとアクセス**で付与します。

## 会議を記録する

メモの保存先ができるように、会議の開始前か終了直後に会議を記録します。

1. **会議**に移動し、**新しい会議**を選択します。
2. **タイトル**、**開始**、**所要時間**を入力します。
3. **参加者**で、参加者ごとに**参加者を追加**を選択します。あなたは**主催者**として自動的に参加者になります。
4. 会議がプロジェクトに関するものであれば、**プロジェクト**でそのプロジェクトを選択します。アクション アイテムをそのプロジェクトのタスクにできるようになります。
5. **閲覧できるユーザー**で**非公開**または**社内**を選びます。**その他の詳細**では**場所**と**ゲスト** (アカウントのない参加者の名前) を追加できます。
6. **作成**を選択します。

**次に起こること:** 会議ページが開き、**議事録はまだ送信されていません**と表示されます。会議はプロジェクトにリンクされるため、プロジェクトの関連レコードにも表示されます。

> **ヒント:** アシスタントに会話の内容とメモから会議を記録してもらうこともできます。たとえば「このメモで昨日のベンダー打ち合わせを記録して」と依頼します。アシスタントは下書きを作成し、整理と送信はあなたが行います。

## メモを入力する

会議の進行に合わせて、会議ページの**メモ**に自分の言葉でメモを入力し、**メモを保存**を選択します。参加者は全員メモを編集できます。

次の目印を付けると、整理機能が要点を見つけやすくなります。

- やるべきことは、行頭に **アクション：** または **TODO** を付けるか、チェックボックス (`- [ ]`) にします。
- 担当者は **@名前** (たとえば `@高橋 大輔`) で示すか、名前とコロンで行を始めます。
- 日付を書きます: `金曜までに`、`10/20`、`10月24日`、`2026-10-20` など。
- 決まったことは、行頭に **決定：** を付けます。
- 質問 (`?` または `？` で終わる行) は未決事項になります。

英語と中国語でも同じ目印を使えます。たとえば **Action:** と **Decision:**、または **待辦：** と **決議：** です。

## メモを議事録に整理する

会議が終わったら、メモを議事録に整理します。

1. 会議ページで**整理**を選択します。保存していないメモは先に保存されます。
2. **整理した議事録**で、**概要**、**決定事項**、**未決事項** (1 行に 1 件) を確認します。
3. アクション アイテムごとに、**やること**、**担当者**、**期限**、**作業する場所** (**ここで追跡**、または会議のプロジェクトのタスク) を確認します。不要なアイテムは**アイテム n を追加**をオフにします。
4. **議事録を保存**を選択するか、**破棄**を選択します。

**次に起こること:** 議事録は保存されますが、まだ送信されません。タスクになるアイテムには**議事録の送信時に NET のタスクになります**と表示されます。あとから内容を変更するには**議事録を編集**を、手動でアクション アイテムを追加するには**アイテムを追加**を選択します。

AI チャット モデルが設定されている場合は、AI がメモと同じ言語で議事録を作成し、ページに**メモから AI が整理**と表示されます。設定されていない場合は、ISBP がメモ内の目印をもとに整理し、**メモから整理**と表示されます。どちらの場合も、保存する前に担当者と日付を確認してください。保存した内容だけが残ります。

> **注:** 担当者は参加者である必要があります。メモに参加していない人の名前がある場合、そのアイテムには担当者が設定されず、**メモでは … となっていますが、参加者ではありません**と表示されます。担当者を選択してください。

## 議事録を送信する

議事録を送信すると、フォローアップが始まります。

1. **議事録を送信**を選択します。
2. 確認画面に、議事録を受け取る参加者の人数、開始されるアクション アイテムの件数、プロジェクトのタスクになる件数が表示されます。**議事録を送信**を選択します。

**次に起こること:**

- 参加者は ISBP とメールで議事録を受け取ります。
- ここで追跡するアイテムの担当者に通知されます。
- プロジェクトのアイテムは、あなたの名前でそのプロジェクトにタスクとして作成されます。担当者が割り当て先になり、期限も引き継がれます。ページには**タスク NET-42, NET-43 を作成しました**と表示され、各アイテムがタスクにリンクされます。プロジェクト自体のルールが適用されます。そのプロジェクトにタスクを追加できない場合や、担当者がプロジェクトのメンバーでない場合、アイテムはここに残り、**ここに残りました:** と理由が表示されます。
- 会議は、作成したタスクにリンクされます。

デモでは、**Network refresh — weekly sync** の議事録が送信済みです。アイテムのうち 2 件は **Network refresh 2026** のタスクで、1 件はここで追跡されています。

## 自分のアクション アイテムに取り組む

**会議 → 自分のアクション アイテム**に移動すると、会議であなたに割り当てられたアイテムを確認できます。

- **自分**はあなたが担当するアイテム、**主催した会議**はあなたが主催した会議のアイテムを表示します。
- **未完了**、**完了**、**すべて**で絞り込めます。
- アイテムが終わったら**完了**を、終わっていなければ**再開**を選択します。

ここで追跡している未完了のアイテムは、**自分の作業**の**アクション アイテム**にも、期限の近い順に表示されます。

プロジェクトのタスクになったアイテムは、ほかのタスクと同じように**プロジェクト**で作業します。タスクが完了するとアイテムも完了と表示され、タスクの担当者が変わるとアイテムも同じように変わります。

## リマインダー

毎朝、ここで追跡しているアイテムの担当者に、期限の前日にリマインダーが届きます (**明日期限**)。期限を過ぎたアイテムは、完了するまで週に 1 回担当者にリマインドされ、初回は主催者にも通知されます。プロジェクトのタスクのリマインダーはプロジェクトから届きます。

受け取り方は**プロファイルと設定 → 通知**で選べます: **自分に割り当てられたアクション アイテム**、**明日期限のアクション アイテム**、**期限を過ぎたアクション アイテム**、**参加した会議の議事録**。

## フォローアップ会議を開く

定例会議では、前回の会議から次の会議を始められます。

1. 会議を開き、**フォローアップ会議**を選択します。

**次に起こること:** タイトル、参加者、プロジェクト、閲覧できるユーザーが同じ下書きの会議が開きます。前回の会議へのリンク (**… のフォローアップ**) と**以前の未完了アイテム**が表示されるので、残っている項目を順に確認できます。

## あとから決定事項を探す

- **検索:** 会議は各ページ上部の検索結果 (**会議**) に表示されます。タイトルや MTG-00042 などの番号で検索できます。
- **アシスタント**は、話し合った内容から会議を探したり (「コア切り替えについて何を決めた?」)、自分のアクション アイテムを一覧にしたり、会議を記録したりできます。すべてあなたの権限で実行されます。
- **プロジェクトのステータス:** プロジェクトの会議の決定事項は、ステータス レポートの**会議での決定事項**セクションに表示され、ステータス報告の**下書きを作成**でも使われます。[ステータス レポートを読む](projects.md#ステータス-レポートを読む)を参照してください。
