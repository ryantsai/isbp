# 用語集

IS Big Platform とこれらのガイドで使用される用語を、画面に表示されるとおりに English、繁體中文、日本語で示します。別の言語で探しているラベルを見つけたり、用語が業務で何を意味するかを確認したりするのに使用してください。

## このガイドでできること

- [用語の一覧](#用語)で用語を調べる (英語の用語のアルファベット順)
- [関連情報](#関連情報)のリンクから、用語を使用しているガイドに移動する

| Roll back                 | 回復                  | ロールバック                 | 適用済みの変更セットを 1 回の操作で元に戻すこと。ただし、その後にオブジェクトが変更されている場合は除きます (繁體中文では、ロールバックされたリリースは 已回復)                                                                       |
| Runs                      | 執行紀錄              | 実行履歴                     | ジョブ、パイプライン、同期ルールの実行の一覧。それぞれに状態とログがあります                                                                                                                                                          |
| Scheduled job             | 排程作業              | スケジュール ジョブ          | スケジュール (cron、間隔、または他のジョブの後) に従って実行される処理: HTTP 呼び出し、SQL、スクリプト、パイプライン                                                                                                                  |
| Service catalog           | 服務目錄              | サービス カタログ            | サービス デスクがチケットとして処理する申請フォーム                                                                                                                                                                                   |
| Service request           | 服務請求              | サービス要求                 | 機器など、誰かが必要としているもののためのチケット (`SR-…`)                                                                                                                                                                           |
| Sessions                  | 工作階段              | セッション                   | 自分のアカウントにサインインしているデバイスとブラウザー                                                                                                                                                                              |
| Shared account            | 共用帳號              | 共有アカウント               | 複数のユーザーが使用するアカウント (サービス アカウントやデバイスの管理者アカウント)。主保管者と利用者一覧があり、一覧から誰かが外れるとパスワードを変更します                                                                        |
| Sign off                  | 核定                  | 確定                         | 棚卸またはアカウント棚卸に対する情報セキュリティ責任者の最終確認。承認ではないため、**承認**には表示されません                                                                                                                        |
| SLA                       | SLA                   | SLA                          | サービス レベル アグリーメント。営業時間で計算される応答と解決の目標                                                                                                                                                                  |
| Stocktake                 | 資產盤點              | 棚卸                         | 情報資産台帳が実態と一致しているかの確認。各管理責任者が資産を確認または修正し、情報セキュリティ責任者が確定します (`STK-…`)                                                                                                          |
| Sync rule                 | 同步規則              | 同期ルール                   | 統合で ServiceDesk Plus または Azure DevOps Server と何を、どの方向に、どのフィールド マッピングで同期するかの定義                                                                                                                    |
| Task                      | 工作項目              | タスク                       | プロジェクト内の作業の単位。ボードとタイムラインに表示されます                                                                                                                                                                        |
| Ticket                    | 工單                  | チケット                     | サービス デスクのレコード: インシデント、サービス要求、問題、変更                                                                                                                                                                     |
| Workload                  | 工作負載              | 作業負荷                     | 1 人あたり週ごとの予定時間を、その人の稼働可能時間と比較したもの                                                                                                                                                                      |

> **ヒント:** 繁體中文では、簽核は承認のプロセス (**簽核**、簽核流程、簽核路徑、待簽核、簽核者) を、核准は判断そのもの (核准、已核准) を表します。紀錄はレコードやログのエントリ (執行紀錄、連結的紀錄) を、記錄は動詞 (「監査ログに記録される」) を表し、実行のログ ファイルは記錄檔です。回復は変更セット、デプロイ、パイプラインの読み込みのロールバック、復原は元に戻す操作です。發佈は公開 (已發佈)、代碼はグループ、ロール、フォーム、アプリケーションのキー (API キーは金鑰)、通道は通知チャネルです。日本語では、permission はアクセス許可と訳され、権限は最小権限 (least privilege) などの決まった用語にのみ使われます。ジョブ、パイプライン、同期ルールの実行の一覧は実行履歴、相互にリンクされたレコードは関連レコードです。ロール名は閲覧者の言語で表示されますが、組織で作成したロールは付けられた名前のままです。ガイドでラベルを引用するときは、その画面の文言をそのまま使用します。
