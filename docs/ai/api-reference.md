# SDK and platform API reference

Signatures and semantics of everything a module uses. The source of truth is the code:

- `packages/sdk/src/manifest.ts` (manifest);
- `packages/sdk/src/server.ts` (`ModuleContext` and server types);
- `packages/sdk/src/web.tsx` (web SDK);
- `packages/ui/src/components/*` (UI kit);
- `packages/contracts/src/*` (shared DTOs).

Names declared by existing modules are in [reference.md](reference.md).

## 1. Manifest (`defineManifest`, from `@isbp/sdk`)

Validated eagerly. A bad manifest throws when the module is imported.

| Field                         | Type                                                                                                                             | Rules / notes                                                                                       |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| `id`                          | `string`                                                                                                                         | kebab-case, 3–40 chars, not reserved                                                                |
| `version`                     | semver                                                                                                                           |                                                                                                     |
| `name`, `description`, `icon` | i18n keys / lucide name                                                                                                          | `<id>.meta.name`, `<id>.meta.description`                                                           |
| `system`                      | `boolean`                                                                                                                        | cannot be disabled (core only)                                                                      |
| `dependsOn`                   | `string[]`                                                                                                                       | modules whose tables you read; enabling requires them                                               |
| `navigation`                  | `{ id, label, href, icon?, permission?, section?: 'main'\|'admin', group?, badge?, order?, children? }[]`                        | `label`/`group` are i18n keys; `href` absolute (`/<id>/…`); hidden without `permission` (any scope) |
| `permissions`                 | `{ key, description, scopes?: ('global'\|'department'\|'record')[] }[]`                                                          | `key` = `<id>.<resource>.<action>`; `description` i18n key; scopes default `['global']`             |
| `roles`                       | `{ key, name, description?, permissions: string[], grantByDefault? }[]`                                                          | patterns allowed (`<id>.*`, `<id>.items.*`); `grantByDefault` grants the "Everyone" group once      |
| `events`                      | `{ emits?: { name, description?, schema? }[], consumes?: string[] }`                                                             | `name` = `<id>.<entity>.<verb_past>`; `schema` Zod; `consumes` lists names handled in `events`      |
| `settings`                    | `{ key, label, description?, type: 'string'\|'text'\|'number'\|'boolean'\|'select'\|'secret', default?, options?, advanced? }[]` | edited in Administration → Modules; read with `ctx.settings.get(key)`; `secret` values sealed       |
| `ai`                          | `{ tools?: { name, description, input: ZodType, permission, destructive? }[], agent?: { name, permissions } }`                   | `name` = `<id>.<verb_noun>`; description ≥ 10 chars, written for a model; handler in `ai`           |
| `search`                      | `{ entities: string[] }`                                                                                                         | with a `search` provider in the server definition                                                   |
| `portal`                      | `{ entries: { id, label, description?, icon?, href, permission?, order? }[] }`                                                   | cards in Requests → "What do you need?"                                                             |
| `workflows`                   | `{ key, name, description?, subject, facts?: ZodType, required?, defaultGraph? }[]`                                              | `key` = `<id>.<name>`; `required` + `defaultGraph` = always approved; handler in `workflows`        |
| `notifications`               | `{ type, defaultChannels?: ('inApp'\|'email')[], mandatory? }[]`                                                                 | text in catalog `<id>.notifications.<type minus id, . and - → _>.{label,title,body}`                |
| `customFields`                | `{ entities: { type, name }[] }`                                                                                                 | admins add fields to `<id>.<type>`; validate with `ctx.fields.validate`                             |
| `records`                     | `{ types: { type, name, icon?, permission }[] }`                                                                                 | full type `<id>.<type>`; resolver in `records`                                                      |
| `taskTypes`                   | `{ type, name, description?, icon?, permission, config: ZodType }[]`                                                             | full type `<id>.<type>`; handler in `taskTypes`; Scheduled Jobs runs them                           |

## 2. `ModuleContext` (server)

Every route, handler, job, AI tool, resolver and seed receives `ctx`. Members:

### Core

| Member                                               | Semantics                                                                                                                                                          |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `ctx.module`                                         | your manifest                                                                                                                                                      |
| `ctx.db`                                             | Drizzle (node-postgres) on the platform database                                                                                                                   |
| `ctx.transaction(fn: (tx) => Promise<T>)`            | runs `fn` in a transaction; pass `{ tx }` to `audit`, `events`, `notifications`, `records`, `portal`, `forms`                                                      |
| `ctx.principal()`                                    | current actor (`{ type: 'user'\|'service'\|'system'\|'ai_agent', id, name, onBehalfOf? }`) from async context                                                      |
| `ctx.isEnabled()`                                    | whether your module is enabled                                                                                                                                     |
| `ctx.logger`                                         | pino logger tagged with the module id (never log secrets or personal data)                                                                                         |
| `ctx.audit.record(entry, { tx?, principal? })`       | `entry = { action, entityType?, entityId?, entityLabel?, changes?, metadata?, outcome?: 'success'\|'failure'\|'denied', category?: 'data'\|'security'\|'system' }` |
| `ctx.audit.diff(before, after, fields?)`             | `{ field: [before, after] }` for changed keys (secrets redacted by name)                                                                                           |
| `ctx.events.publish(name, payload, { tx? })`         | transactional outbox; delivered after commit to every module that `consumes` it                                                                                    |
| `ctx.jobs.enqueue(name, data, { delayMs?, jobId? })` | queues one of your `jobs` (dedupe with `jobId`); the job's declared `attempts`/`backoffMs` apply                                                                   |
| `ctx.settings.get<T>(key)` / `all()`                 | admin-edited setting or the manifest default                                                                                                                       |
| `ctx.rbac.permissionsFor(userId)`                    | another user's effective `PermissionSet`                                                                                                                           |

### Phase 1: approvals, notifications, forms, portal, custom fields

| Member                                                                                                                                                        | Semantics                                                                                                                                                                                                                                                                                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ctx.workflows.start(triggerKey, { subject: { type, id, label, href? }, facts?, requesterId, subjectUserId?, definitionId? }, { tx? })`                       | starts the workflow bound to your trigger. Returns `null` when none is bound and the trigger isn't `required`, otherwise `{ instanceId, status }`. Completion arrives at `workflows[trigger].onCompleted({ instanceId, triggerKey, subjectType, subjectId, outcome: 'approved'\|'rejected'\|'cancelled', requesterId, comment }, ctx)` |
| `ctx.workflows.cancel(instanceId, reason?, { tx? })`                                                                                                          | closes pending tasks                                                                                                                                                                                                                                                                                                                   |
| `ctx.notifications.notify({ type, recipients, params?, href?, data? }, { tx? })`                                                                              | in-app rows commit with `tx`; email/Teams/Slack go out from the worker; text comes from your catalog in each recipient's locale and time zone                                                                                                                                                                                          |
| `ctx.notifications.broadcast({ type, params?, href? }, { tx? })`                                                                                              | posts to the organisation's subscribed channels                                                                                                                                                                                                                                                                                        |
| `ctx.fields.definitions(entityType)` / `validate(entityType, input, existing?)`                                                                               | custom fields of `<id>.<type>`; `validate` throws 400 with `details.fields`                                                                                                                                                                                                                                                            |
| `ctx.forms.submission(id)` / `published()` / `setFulfilment(submissionId, { reference, href, state, statusKey, tone? }\|null, { tx? })`                       | Phase 1 forms; show your progress on a request                                                                                                                                                                                                                                                                                         |
| `ctx.portal.track({ kind, id, reference, title, state: 'open'\|'closed', statusKey, tone?, href, icon?, people, createdAt? }, { tx? })` / `untrack(kind, id)` | your records under the requester's "My requests"                                                                                                                                                                                                                                                                                       |

### Phase 2: AI gateway

| Member                                                                                                           | Semantics                                                                                                               |
| ---------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `ctx.ai.status()`                                                                                                | `{ chat: { available, provider, model }, embeddings, vectorStore }`. Without a chat model, features need a builtin mode |
| `ctx.ai.chat({ feature, system?, messages, tools?, schema?, effort?, maxTokens? }, { auth? })`                   | masked, budgeted, logged per `feature`. `schema` gives typed `output`. Throws 409 `AI_NOT_CONFIGURED` without a model   |
| `ctx.ai.stream(req, { auth? })`                                                                                  | async iterable of `{ type: 'text', delta }` then `{ type: 'done', result }`                                             |
| `ctx.ai.embed(texts, { feature })`                                                                               | unit vectors (builtin embedder works offline)                                                                           |
| `ctx.ai.index.upsert({ type, id, title, text, locale?, href?, acl: { permission, scope?, users? }, metadata? })` | call **after commit** (from your own event handler)                                                                     |
| `ctx.ai.index.remove(type, id)` / `search(query, { types, auth, limit?, filter?, excludeIds? })`                 | hybrid search, ACL-filtered for `auth`                                                                                  |
| `ctx.ai.tools.list(auth)` / `invoke(name, input, { auth, confirmed? })`                                          | the cross-module tool registry (same permissions as the UI; destructive tools need `confirmed`)                         |
| `ctx.ai.agent()`                                                                                                 | your module's `ai.agent` identity as an `AuthContext`, for background AI work                                           |

### Phase 3: records, files, secrets

| Member                                                                                                      | Semantics                                                                                              |
| ----------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `ctx.records.resolve(refs, auth)` / `get(ref, auth)`                                                        | resolve `{ type, id }` refs through their modules' resolvers; hidden records are omitted               |
| `ctx.records.search(query, { auth, types?, limit? })`                                                       | pickers across modules                                                                                 |
| `ctx.records.link(a, b, { tx? })` / `unlink(a, b)`                                                          | symmetric, idempotent, audited, publishes `core.record.linked`/`unlinked`. **Check permissions first** |
| `ctx.records.links(ref, { auth, types? })`                                                                  | links with the other side resolved for `auth` (`hidden: 'forbidden'\|'unavailable'` otherwise)         |
| `ctx.records.linked(ref, { types?, tx? })`                                                                  | raw refs (no permission filtering) for your own logic                                                  |
| `ctx.records.counts(refs)` / `forget(ref, { tx? })`                                                         | link badges; drop links and files of a deleted record                                                  |
| `ctx.files.list(ref)` / `attach(ref, { name, contentType?, data })` / `get(id)` / `open(id)` / `remove(id)` | attachments with size, type, sniffing and malware checks (422 `FILE_REJECTED`, 413 `FILE_TOO_LARGE`)   |
| `ctx.secrets.seal(plain)` / `open(sealed)`                                                                  | AES-256-GCM with the master key (rotation-aware)                                                       |

### Phase 4: databases, task types, HTTP, cache, sandbox

| Member                                                                                                                                                                          | Semantics                                                                                                                                                                                                                                                                                 |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ctx.databases.list({ purpose?, enabledOnly? })` / `get(id)`                                                                                                                    | registered connections (`{ id, key, name, engine, host, port, database, username, purposes, readOnly, enabled, status, serverVersion, timeoutMs, maxRows }`); never credentials                                                                                                           |
| `ctx.databases.query(id, sql, { purpose, params?, types?, maxRows?, timeoutMs?, readOnly?, signal? })`                                                                          | one statement, `:name` placeholders, list params expand. Returns `{ columns, rows, truncated, affected, durationMs }`. Limits are clamped to the connection's                                                                                                                             |
| `ctx.databases.call(id, procedure, args, { purpose, … })`                                                                                                                       | procedure or function from `catalog()`, named arguments; `outputs` for OUT params                                                                                                                                                                                                         |
| `ctx.databases.stream(id, sql, { purpose, batchSize?, … })`                                                                                                                     | async iterable of `{ columns, rows }` batches (server-side cursor)                                                                                                                                                                                                                        |
| `ctx.databases.writer(id, { schema?, name }, { purpose, columns, mode: 'insert'\|'upsert'\|'replace', keys?, timeoutMs?, signal? })`                                            | `{ write(rows), commit(), rollback() }` in one transaction; refused on read-only connections (409 `CONNECTION_READ_ONLY`)                                                                                                                                                                 |
| `ctx.databases.catalog(id, { purpose, refresh? })`                                                                                                                              | `{ defaultSchema, schemas, tables[{ schema, name, kind, columns[{ name, type, nullable, key }] }], procedures[{ schema, name, kind, returns, parameters }], truncated }`                                                                                                                  |
| _errors_                                                                                                                                                                        | 403 `CONNECTION_PURPOSE`, 404 `NOT_FOUND`, 409 `CONNECTION_DISABLED`, 422 `DATABASE_ERROR` with `details: { kind, dbCode, message }` (`kind`: `auth`, `connect`, `timeout`, `syntax`, `permission`, `not_found`, `constraint`, `read_only`, `cancelled`, `other`), 400 for bad parameters |
| `ctx.taskTypes.list(auth?)`                                                                                                                                                     | `{ type, moduleId, name, description, icon, permission, configSchema }[]` of enabled modules (filtered by permission)                                                                                                                                                                     |
| `ctx.taskTypes.validate(type, config, auth)` / `describe(type, config)` / `run(type, config, task)`                                                                             | parse + the owner's `validate` (400/403/404), label + href, run in the owner's context                                                                                                                                                                                                    |
| `ctx.http.request(url, { method?, headers?, body?, timeoutMs?, maxBytes?, allowHosts?, signal? })`                                                                              | `{ status, headers, body: Buffer, truncated, durationMs }`. 422 `TARGET_BLOCKED` (private/metadata, not http(s), credentials in URL); 502 `UPSTREAM_FAILED` (`details.reason`: `timeout`, `network`, `cancelled`). No redirects followed                                                  |
| `ctx.cache.get/set(key, value, ttlSeconds)/delete/increment(key, ttl)`                                                                                                          | JSON in Redis under `isbp:m:<id>:`                                                                                                                                                                                                                                                        |
| `ctx.cache.rateLimit(key, limit, windowSeconds)`                                                                                                                                | `{ allowed, remaining, resetSeconds }` (fixed window)                                                                                                                                                                                                                                     |
| `ctx.sandbox.status()`                                                                                                                                                          | `{ runner: 'none'\|'local'\|'docker'\|'kubernetes', isolated, images }`                                                                                                                                                                                                                   |
| `ctx.sandbox.run({ image, language: 'python'\|'node'\|'powershell'\|'shell', script, env?, timeoutMs, cpu?, memoryMb?, network?: 'none'\|'egress', labels?, signal?, onLog? })` | `{ exitCode, timedOut, cancelled, durationMs }`; 422 `SANDBOX_UNAVAILABLE` (no runner, image not allowed, limits)                                                                                                                                                                         |

Task handlers receive `task: { runId, jobId, attempt, scheduledFor, lastSuccessAt, timeoutMs?, signal, log(message, level?) }`
and return `{ summary?, metrics?, href? }`.

## 3. Authorization: `AuthContext` and route config

`req.auth` (routes), the `auth` argument (resolvers, tools), `ctx.ai.agent()`:

| Member                           | Semantics                                                                                      |
| -------------------------------- | ---------------------------------------------------------------------------------------------- |
| `principal`, `user`, `client`    | who is calling (`user` is null for API clients and agents; `client` set for API clients)       |
| `can(permission, resource?)`     | `resource = { departmentId? }` or `{ recordType, recordId }`; without `resource`: global grant |
| `require(permission, resource?)` | throws 403 and audits the denial                                                               |
| `reach(permission)`              | `{ global, departmentIds, records: [{ type, id }] }` — build list filters from it              |
| `permissions.hasAny(p)`          | holds `p` at any scope                                                                         |

Route `config`:

- `permission`: a string or string[] (all required).
- `scoped: true`: any scope passes the guard, and you check the scope.
- `public: true`: no session.
- `csrf: false`: skips the CSRF check (only for flows that carry their own proof).
- `rateLimit: { max, timeWindow }`.

Patterns in roles: `*`, `<id>.*`, `<id>.<resource>.*`.

## 4. HTTP helpers and contracts

| Import                                                                                                                                                                                | What                                                                               |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| `@isbp/sdk` → `HttpError`, `ErrorCodes`, `httpErrors.{badRequest,unauthenticated,forbidden,notFound,conflict}`                                                                        | errors the kernel renders as `{ error: { code, message, details, requestId } }`    |
| `@isbp/sdk` → `listQuerySchema`, `pageSchema(item)`, `Page<T>`                                                                                                                        | `?page&pageSize&q&sort` (`-field` = desc) and `{ items, total, page, pageSize }`   |
| `@isbp/sdk/server` → `likePattern(term)`                                                                                                                                              | escape a search term for `ilike`                                                   |
| `@isbp/sdk` → `formatRecordRef`, `parseRecordRef`                                                                                                                                     | `itsm.ticket:<id>` ↔ `{ type, id }`                                                |
| `@isbp/contracts` → `dateTime`                                                                                                                                                        | ISO string ⇄ `Date` codec for every timestamp field                                |
| `@isbp/contracts` → `id`, `ref`, `keySchema`, `localeSchema`                                                                                                                          | uuid; `{ id, name }`; `[a-z][a-z0-9-]*` keys; supported locales                    |
| `@isbp/contracts` → `dbConnectionSummarySchema`, `catalogSchema`, `databaseErrorSchema`, `taskTypeInfoSchema`, `TaskConfigSlotProps`, `RecordPanelSlotProps`, `UserOverviewSlotProps` | shared platform DTOs and slot props                                                |
| `@isbp/sql/params` (browser-safe)                                                                                                                                                     | `parameterNames(sql, engine)`, `writeKeywords`, `statementCount`, `scan`, `coerce` |

DTO types for the web are `z.input<typeof schema>` (dates as strings). Services return `Date`s, and the response
schema serialises them.

## 5. Web SDK (`@isbp/sdk/web`)

| Export                                                   | Use                                                                                                   |
| -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `defineWebModule(manifest, { routes, slots? })`          | routes `{ path, load, permission? }` relative to `/<id>`; slots `{ slot, load, permission?, order? }` |
| `WebPageProps`                                           | `{ params: Record<string, string> }` passed to pages                                                  |
| `usePlatform()`                                          | `{ user, grants, csrfToken, enabledModules, permissions }`                                            |
| `useCan(permission, resource?)`                          | UI gating only (the API decides)                                                                      |
